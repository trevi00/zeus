# Root challenges for Atlas / proposal discussion

Read root-initial and the full delegated Codex reports before discussion. The
root can hash inert source bytes without executing source programs; our metadata
checks establish the pins separately. Claude's source-execution restriction is
not a claim that hashing is intrinsically forbidden or that identity is unknowable.

1. Static builtin membership is not the complete effective registry: _graduated()
   adds entries from separate state. Label your thirteen as not builtin, not proven
   unregistered or non-gating today. A malformed state file causing silent loss
   needs the actual loader path traced, not only the broad except in registry.
2. A complete literal grep is not a complete semantic call graph. Report no matched
   references in the searched tree; dynamic/aliased/generated callers are not
   excluded. The staging helper's SHOULD contract and named writers need actual
   bodies traced before claiming all production wiring absent.
3. Harness code has already changed relative to several cards: cohesion is bounded
   to400 commits; mount contract derives role services; apply_via_sandbox already
   reconfirms. Its failure-set intersection differs from suite_cmd all-green policy.
   Your assertions that those mechanisms are absent/hardcoded repeat stale prose.
4. Historical bidirectional container/console/mutation tests were not replayed.
   Do not call cards cleanly resolved or actual kernel enforcement verified here.
   One approval/resolution overlap also prevents calling their sets disjoint and
   does not prove independent lifecycles or causation.
5. No-mock capability does not follow from validator filenames. The Codex report
   connects many cards to lexical/existence checks with missing/skip/empty behavior.
   Similarly er.py does not implement the broad Mermaid parsing claimed by the card,
   logical.py does not prove normalization, and commit-layer scanning does not
   establish an exact-commit whole semantic dependency graph.
6. stdout parsing remains log interpretation. The strongest stdout contract card
   includes an example that ignores exit/stderr and can treat silent failure as
   clean. run_all test execution, registry invocation and validate_project have
   different semantics; registration alone does not run every gate on every CI.
7. L2's unknown-caller rejection is a useful stricter default, not proof that
   ModuleSpec is an unforgeable actor or a complete runtime capability boundary.
8. Matching six LOC values now does not prove other values were ever accurate or
   establish the historical cause of drift. Structural count arithmetic is limited
   evidence, not detector qualification or safe graduation approval.
9. Reviewer read-only can mean observation without implementation mutation while
   a coordinator persists an assessment. Source agent tool self-reports are not
   authenticated spawn receipts; do not turn that ambiguity into a confirmed bug.
10. Incident severity and measured recurrence probability are separate. Unmeasured
    frequency warrants uncertainty, but does not itself prove a severe credible
    consequence should be downgraded. No current ticket state is changed here.
