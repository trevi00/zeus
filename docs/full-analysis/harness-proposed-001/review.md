# Harness proposed 001: independent static review

All 17 primary JSON bodies were freshly read, including corrections and residual fields. This is a completed bounded body review, not completed implementation, experiment replication, or adoption. Exact source revision, bytes, Git blobs, SHA-256, prior unreviewed rows, and supporting ranges are in the accompanying JSON records. Source commands and historical permission statements were treated solely as data. Original execution, imports, probes, network requests, installations and Claude calls: zero.

## Cross-cutting findings

These proposals are evolving research records rather than normalized issue states. Several retain an obsolete title, recommendation or residual alongside a later correction. A `measured` label does not establish a reproducible current result, and a `resolved` object can describe only one axis. Current pinned implementation already contains the freshness gate, dropped-candidate display, hook journal and permanent-delivery-failure callback. Conversely, schema gaps and incomplete result consumption remain visible. No blanket open/closed judgment was inferred from the JSON filenames or labels.

The common proposal consumer reads JSON, supplies a missing slug, and reports JSON parse failures; ranking consumes proposal evidence and independently derived resolution events (s18). It does not turn the prose's approval or historical PASS into present authorization. Freshness reads prose dates and cited paths, not a complete immutable evidence package. `freshness_of` returns None both for a non-proposal and for a missing proposal; the arming gate treats a returned None as outside scope. A disappearing proposal between ranking and assessment is therefore not distinguished from legitimate exemption in these ranges. This is a static seam, not a reproduced race.

Zeus should retain Git versions of requirements, the user's complete eight-stage SDD definitions, original acceptance oracles, policies and model qualification definitions. PG should own durable runtime attempts, leases, actor-bound approvals, result receipts, evidence provenance, amendments and retries. Historical Git JSONL runtime authority is not adopted as Zeus's authority. A model tier, role name, approval string, nonempty acceptance list, healthy service or successful mock does not establish qualified execution or actual human acceptance. A learning note based on a title or transport failure is operational experience, not review of the source's unseen body. These are adaptation requirements, not claims about current Zeus equivalence.
