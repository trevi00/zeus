- **brain**: brain_autopush 1~185는 repo별 임시 worktree를 재사용·강제 cleanup하지만 같은 repo 동시 호출 lock이 없고 finally cleanup 자체가 예외를 던질 수 있어 'never raises'와 다르다. add/rm rc 일부를 무시한다. origin ls-remote 오류를 branch 부재로 해석하고 no-change에도 pushed=True를 반환한다. 테스트의 clean fixture만으로 실패·동시성·비밀자료 제외를 검증할 수 없다. brain_git_status 1~131은 설명의 content diff와 달리 JSONL ID 집합 포함을 사용하고 graduation은 비교하지 않는다. 같은 ID 내용 변경/철회 이유 변경/손상 행은 안전 오판 가능성이 있다. brain_store 1~332은 missing schema를 허용하고 모든 malformed 행/읽기 오류를 skip하며 overlay가 동일 ID를 덮는다. fixed .tmp와 다중 파일 순차 갱신은 transaction/CAS가 아니다. save의 operator-only라는 오래된 테스트 주석과 달리 source는 Stop auto-save도 명시한다. graduation 149~210의 restore_streak는 max streak와 epoch0을 쓰지만 기존 ready=True를 지우지 않는다. primary는 ready/실제 재검증/졸업을 검사하지 않는다. cron/run_brain_push 43~123은 공개 문자열 env token을 비교하고 save 후 ack/flag consume을 먼저 하며 push 실패에도 rc0이다. 테스트5개는 이 caller의 승인·실패 반환 정책을 검사하지 않는다.
