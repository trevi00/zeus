# 미완료와 시험 경계

primary 19개는 전문을 직접 읽었다. handoff_drift의 도구 출력에서 생긴 393–410 부근 누락은 같은 원본 구간 재독으로 메웠다. supporting은 명시 구간만 읽었으며 다른 파일의 전수 독해를 주장하지 않는다.

- 졸업의 실제 scan/mtime/복원/동시 전이, flag·state·history의 원자성, 사람 승인 주체 및 registry 갱신 효과는 미실행이다.
- L1→L2 반복 승격·중복 evidence·철회 후 support·분모 및 partial 저장 문제는 정적 경로 추론이다. 현재 운영 결함을 재현하지 않았다.
- 기억의 원자료 사실성, 실제 독립 세션·모델 자격·사용자 경험 인수와 연결한 전체 provenance 검증은 미완료다.
- 모든 hook host schema 수용·권한 강제·프로세스 timeout·신호 전달, Windows/Linux/WSL·타임존·파일 경합 검증은 미완료다.
- graph 참조를 production 호출 closure로 승격하지 않았다. config는 명시 구간만 읽었다. 모든 시험과 동적 등록의 전체 추적은 남아 있다.
- 예상한 test_ground_or_drop.py와 test_intent_doc_floor.py 경로는 없었다. 대체 시험/probe의 존재나 의미 검토 완료를 주장하지 않는다. 다른 시험도 supporting 범위의 오라클/fixture만 분석했다.
- 원문 과거 승인·LOCK·실측·PASS·자동 OK는 현재 사용자 권한이나 이번 실행 성공이 아니다. 원본 import/명령/probe/시험/네트워크/설치 0회, 차단 probe 재시도 0회다.
- 전체 closure, 라이선스/재배포, 현행 vendor 사실, 실제 Claude 영역 전체 공동 검토, 실제 사람 승인 및 Zeus 구현 등가/채택은 모두 미완료다. 구현은 root 담당이며 이 폴더는 정적 checkpoint다.
