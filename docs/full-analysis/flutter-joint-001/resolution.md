- 결제 예제의 네이티브 판정은 `resultCode == Activity.RESULT_OK && ansCode == "0000"`인데,
  반환하는 `responseCode`는 실패 분기에서도 원래 `ansCode`다. Dart 예제는
  `responseCode == '0000'`만으로 성공을 계산한다. 따라서 실패 resultCode와
  성공 문자열이 함께 입력되는 조건에서 이 예제 조합은 성공으로 읽힌다.
  원문 대입은 `paygate-kovan.md:149`이며 Claude 답변의 150행 표기는 한 줄 어긋난다.

  생략된 필드나 실제 앱이 성공 플래그를 전달하고 사용하는지는 미확인이다.
