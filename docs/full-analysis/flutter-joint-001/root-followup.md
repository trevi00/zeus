eight stages are: spec/scope discussion; design/interaction analysis; component/UI
implementation; self-verification; alpha deployment; QA evidence and human approval;
progressive production deployment; CS/monitoring/incident response, then iterate.
Astra designs and verifies the beginning/end; Sol handles important implementation
after qualified guardrail transfer; Terra handles simple implementation only after
equivalent qualification. These definitions are available, while actual qualification
is unproved. Missing qualification is not a request for the user to repeat them.

1. A fixed key literal is present in documentation; do not reproduce it. Current
   shipped use, data access and applicability to every store are unknown. A key
   alone does not grant possession of every database. Nor was its value copied into
   every Zeus artifact: our reports omit it and metadata records only identities.
   One validator's narrow rules do not prove no secret gate exists anywhere.
2. Co-loading and precedence need actual parser/matcher tracing. The Codex report
   finds dart versus flutter directory candidates, inline comments retained in
   extension paths, nonrecursive scans and frontmatter-less content modules. A
   keyword overlap does not establish all cited bodies are actually co-loaded.
3. [refactor] is absent from COMPANY_COMMIT_PREFIXES, but git_flow prints FAIL without
   setting a nonzero exit in the inspected flow. Distinguish a lexical mismatch,
   printed result, consumer enforcement and actual rejected commit. Do not make the
   company's Git policy canonical for Zeus merely because it matches that validator.
4. Unit/widget fakes do not inherently contradict real no-mock acceptance. The
   testing matrix distinguishes native/device limits. Missing actual acceptance
   remains a gap; a fake unit test is not itself a violation. No PostgreSQL mentions
   do not make the experience non-contributing: client storage is a different
   boundary from the harness PG runtime ledger.
5. Source claims about Drift transaction semantics, KOVAN/EasyPOS transport and
   current Flutter/iOS conventions remain unverified. Do not call a vendor PDF
   interpretation a correct refutation after saying that PDF was not read.
   Snippets with omitted bodies/declarations were not compiled; qualify apparent
   inconsistencies instead of claiming a measured compile failure of the unseen app.
6. External local directories were not inspected. Their absence from the pin is
   not proof they do not exist on this host, nor that they are forever unreviewable.
7. Socket documentation includes timeout paths. Do not infer every wait is infinite
   from another paragraph without the original app's full call graph.
