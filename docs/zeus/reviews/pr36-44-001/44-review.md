**[P2] 정규화한 YAML 키의 중복이 조용히 덮어쓰기 됨**

위치: `adapters/skill_routing.py:33–44`

frontmatter에 `keywords: [safe]`와 `"keywords ": [overridden]`를 같이 넣으면 YAML loader는 서로 다른 원본 키로 받아들이고, 이후 key.strip()에서 같은 키가 되어 최종 keywords가 overridden으로 덮어써집니다. 실제 frontmatter() 호출에서 오류 없이 수용되는 것을 확인했습니다.

수정 요청: 키를 정규화한 뒤 중복 여부를 검사하거나 정규화가 필요한 키를 명시적으로 거절해 주세요. 인용된 앞뒤 공백 키와 일반 키의 충돌을 실제 matcher 입력까지 확인하는 회귀 테스트가 필요합니다.
