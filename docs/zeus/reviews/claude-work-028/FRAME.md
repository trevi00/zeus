# PR #103 검토 틀

대상 1a161111b60d6538de3386927143d96b55cb2167. base PR #101 fix/disposable-service-readiness. PR #101 재검토/병합을 대신하지 않는다.

목표: 일회용 검증 스택의 WSL 포트 거부 가능성을 줄이되, 실제 관측 범위·양쪽 호스트의 선택 조건·자원 소유권을 정확하게 유지한다. 자동 재시작은 이번 변경에 요구하지 않는다.

| 조건 | 전체 경로/결정 검사 |
|---|---|
| 재현과 과거 원인 구분 | reproduce/sockets/residual 원본, 당시 실패의 점유자 관측 여부, 관측 기간, 재개 탐침의 시작 시점 |
| 선택 포트의 사용 가능 범위 | range 조회→후보 bind→해제→compose 게시→되읽기→실제 요청→identity. Windows/WSL의 서로 다른 namespace 포함 |
| 점유·경합·fallback | 사전 점유와 해제 후 경합 구분, 범위 미확인/고갈 시 약화 상태의 보고 |
| 측정 도구 소유권 | 컨테이너 생성·실패·타임아웃·중단·최종 정리. 다른 실행의 자원 침범 없음 |
| 증거 결속 | 두 호스트 receipt digest/동일 runtime, 최신 head CI, 독립 검사 결과와 주입 범위 |

판정: 기존 base의 수용 부분은 유지한다. 위 표를 한 번에 검토해 관련 수정만 통합해서 전달한다. 실측상 남는 TOCTOU 자체를 전면 제거하도록 범위를 확대하지 않는다. 오류를 자동 재시작으로 숨기지 않는다. 과거 원인의 단정은 관측된 범위로 정정하면 되며, 모든 과거 장애를 재현할 때까지 보류하지 않는다.
