## 수용 범위

1. Windows 선택기가 실제 WSL 점유 포트를 제외하는지 RNG를 점유 포트에 고정해 확인한다. 조회 범위와 미관측·fallback은 보고에 구분한다.
2. 탐침은 UUID·라벨로 자기 컨테이너만 정리한다. 게시 거절로 Created 상태에 남은 컨테이너의 회수도 확인한다.
3. 과거 장애 원인은 유력 가설로 남긴다. 재현 기제와 과거 일곱 건의 원인 확정을 구분하고, 관측 시간·집계 정정을 수용한다.
4. #101의 미관측 판정·진단 시간 예산·반환 스냅샷 반례와 기존 자원 회수 회귀를 함께 확인한다.

## 남기는 제한

- 선택 검사와 게시 사이의 경합은 남는다. 준비 실패는 제한된 시간 안에 실패·진단으로 처리하며 자동 컨테이너 재시작은 추가하지 않는다.
- 원격 데몬·다른 배포판 구성까지 현재 PC의 관측을 일반화하지 않는다.
- 탐침 생성 자체의 timeout 등 드문 도구 실패에 대한 정리·보고 보완은 후속 개선 대상이다. 운영 컨테이너 임의 삭제와는 구분한다.
- 환경 준비 PR 수용은 전체 무인운영 인수를 뜻하지 않는다. 다음 관문은 실제 Zeus 작업 배정→Claude 구현→Codex 검토→수정→병합 흐름이다.
