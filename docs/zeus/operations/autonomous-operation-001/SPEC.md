- [ ] A goal/criterion-backed candidate is chosen without manual enqueue, after SSOT and primary-source
  research where needed. Reuse/extend/build and alternatives are recorded before implementation.
- [ ] Claude implements and independent Codex reviews the exact candidate; critical acceptance
  failures cause bounded correction, not a new endless investigation. Rejection is preserved.
- [ ] Exact reviewed code passes its checks and enters a canary; the real current operating worker
  consumes it, with active revision/image/profile receipts and known-good rollback.

  side effects; an unprovable effect becomes an exception. Two distinct similar failures initiate
  research via existing owners, not blind re-execution or automatic weakening of checks.
- [ ] A controlled regression rolls back and pauses only the affected family. Repeated delivery and
  service restart preserve claims, attempts, evidence and ownership without duplicated execution.
- [ ] A second useful item is selected after the first completes; independent eligible projects can
  progress. No human relay or this chat is required between those transitions.
- [ ] Monitor/report links goal -> candidate -> research/decision -> task -> inspection/review ->

  identities and severity; missing evidence/usage is unknown, never zero or success.

Initial operating canary is finite and checklist-driven: two useful items, one recoverable failure,
one rejected/rollback control, one duplicate/restart control. Fault-injected controls are labelled and
cannot be reported as naturally occurring incidents. Upon completion the same verified policy can
run continuously over the approved portfolio; exhausted backlog means idle, not invented busywork.
