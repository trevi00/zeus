# Zeus 운영 목표와 잔여

기준: 2026-09-16, main `9d503d0`. 이 문서는 현재 운영 마일스톤을 고정한다. 전체 자산 분석의 분모·미커밋 조사 기록은 기존 goal-progress와 full-analysis 원장을 보존하며, 여기서 완료로 승격하지 않는다.

## 최종 사용자 목표

로컬 Claude 하네스의 경험·자산을 분석해 필요한 것을 Zeus에 흡수하고, Codex가 목표·설계·검토를 맡고 Claude가 구현하는 무인 자율 개선 운영을 만든다. Git의 명세와 PG의 검증된 원장, Redis Streams의 six-W 메시지, 일반·개발·운영 로그를 연결한다. 이후 code-tutor-ai를 첫 실제 프로젝트로 수행한다. SDD·실사용 인수·실기기 요구는 유지한다. Samsung 기기 작업은 유예 상태다.

## 현재 운영 마일스톤

운영자가 목표·범위·예산을 한 번 지정하면, 승인된 잔여 한 건을 Claude 구현 → 검증 → Codex 검토 → 증거와 인계 기록까지 사람의 메시지 중계 없이 처리하고, 수용 또는 실패/미확정/예산 소진에서 정지한다. 사람 인수·최종 병합/배포 권한과 무제한 작업 선정은 포함하지 않는다.

이 표는 기능 작업 개수가 아닌 운영 인수 조건이다. 완료된 코드/테스트와 실제 경로 실측을 구분한다. 전체 자산 흡수와 실제 제품 인수 완료율로 환산하지 않는다.

## 작업 선정과 자가개선 규칙

모든 다음 작업은 목표 개정, 아직 충족하지 못한 조건, 해당 작업이 그 조건을 해소하는 이유, 수용 증거, 호출·시간 한도에 연결한다. 연결되지 않는 발견은 참고/후속으로 두며 현재 작업에 이어 붙이지 않는다. 금전·중복 실행·증거 손실·잘못된 승인 등 실제 중대 위반만 현재 수용을 막는다. 이전에 수용된 경계는 새로운 변경/실패 증거가 있을 때만 다시 검토한다.

주 지표는 고정된 분모의 검증된 종료 조건 수 / 전체 조건 수, 남은 조건 수, 재개방 수다. PR·커밋·테스트·리뷰 횟수는 활동량일 뿐 진척이 아니다. 모델 자가평가와 GitHub 원격 CLOSED도 로컬 증거 기반 종료를 대신하지 못한다. 목표/분모가 바뀌면 새 개정으로 표시하고 이전 개정 대비 개선율을 계산하지 않는다.

자가개선 후보는 같은 목표와 오라클의 전후 결과에서 새로 해소된 조건과 퇴행한 조건을 각각 보고해야 한다. 비용·시간 효율은 실측 사용량과 비교 가능한 실행 분모가 있을 때만 산출한다. 미측정은 unknown이다. 지표는 선정·검토 근거이지 자동 예산 증액·승격·병합 권한이 아니다.
