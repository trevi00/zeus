# 조사 규율 지침 흡수 결과

2026-09-16. SPEC.md와 source.json에 따라 baldrix `skills/_common/investigation-discipline.md`(7f2d97d)의
선별된 원칙만 패키지된 worker-v1 문서에 흡수했다.

## 변경한 것

- `worker-profile-v1.md`에 "Assigned bug investigations" 절 하나를 추가했다. 할당된 결함 조사·수정
  작업에만 적용되며, 원인 주장 전 실제 실패 증거와 담당 코드 추적, 관찰·가설·미지의 구분과 측정
  보고 조건, 격리된 복사본에서의 회귀 테스트 확인, 할당 범위·예산·수용 기준에서 멈추고 실패 시도를
  보존하는 것, 지침과 훅 영수증이 준수 증명이 아니라는 점을 담았다. 문장은 새로 썼고 상류 텍스트를
  복사하지 않았다.
- `worker-profile-v1.json`의 `document_sha256`를 기존 정규화(CRLF를 LF로, UTF-8) 규약으로 다시 계산했고,
  source.json의 source/path/commit/blob/pinned_sha256/scope/disposition 값을 그대로 쓴 출처 항목 하나를
  추가했다. 기존 출처 항목, 훅 다이제스트, permissions, id, version은 그대로다.

## 채택하지 않은 것

- 상류 훅, 모듈, 전역 설정, 고정 경로 가드, 자동 재시도 규칙, 라우팅·데몬은 설치하지 않았다.
- 상류의 사고 사례 서술은 문서상의 주장일 뿐 Zeus에서 재현된 증거가 아니므로 옮기지 않았다.
- 조사를 매번 반복되는 필수 게이트로 만들지 않았고, 권한·런타임·테스트는 바꾸지 않았다.

## 한계

- 이 구현 호출 자체는 이전 패키지 프로필로 시작했으므로 새 지침을 사용한 것이 아니다. 이후 호출부터
  수락된 문서를 로드한다.
- 이 작업이 증명하는 것은 문서 구성과 전달 호환성(로드, 변조 거부, 훅 전달)이며 모델 행동의 개선이
  아니다. 지침 전달은 준수의 증거가 아니고, 기존 검토 권한은 변하지 않는다.
