## Fixed acceptance matrix for the design

| Boundary | Required decision/evidence |
|---|---|
| Normal | Exact failure -> scoped investigation -> named correction -> independently verified result |
| Minor deviation | Record and continue with explicit authority; do not invent successful execution |
| Material failure | Reachable acceptance breach and evidence; block only affected scope |
| Recurrence | Distinct attempts, not replayed events; two strikes trigger source-backed investigation |
| Ownership/restart | One successor claim, fencing, no retry from unknown execution; preserve lineage |
| Timeout/cancel | Bounded work and cleanup; no silent budget or deadline increase |
| Missing evidence | Unknown remains unknown; model prose never becomes verified knowledge |
